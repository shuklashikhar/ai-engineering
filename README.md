
# 100 Days of AI Engineering

## Day 1: Python and LLM API Integration

### What I built
A Python command-line application that accepts
a user prompt and generates an answer using an LLM API.

### Technologies
- Python
- Groq API
- python-dotenv
- Git and GitHub

### Run locally
1. Create and activate a virtual environment.
2. Install dependencies using `pip install -r requirements.txt`.
3. Add `GROQ_API_KEY` to your `.env` file.
4. Run `python main.py`.

### Concepts learned
- Virtual environments
- Environment variables
- API integration
- Prompt messages
- Error handling
